# Jay Domagtoy – Personal Portfolio

A responsive portfolio built with HTML, CSS and JavaScript (Font Awesome + Google Fonts via CDN).

## Run
Open `index.html` in a browser (internet needed for fonts/icons).

## Customize
- **Photo:** add `images/profile.jpg` (until then, "JD" initials show).
- **Project links:** replace each `href="#"` on the "View Project" buttons.
- **Contact info / social links:** edit the Contact section and footer in `index.html`.
- **Education, timeline, skill percentages:** edit the text in `index.html`.
- **Colors:** change the variables at the top of `css/style.css`.
- **Contact form:** it validates only; connect it to Formspree or a PHP/Node backend to send mail.

## Deploy
Upload the folder to GitHub Pages, Netlify, or Vercel.
